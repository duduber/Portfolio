DUARTE BERARDO — PORTEFÓLIO

Estrutura:
- index.html
- style.css
- script.js
- assets/profile.jpg       (fotografia de perfil, opcional)
- assets/paradox.jpg       (imagem do projeto Into the Abyss)
- assets/chest.jpg         (imagem do projeto ChestCount)
- documents/cv.pdf         (currículo, opcional)
- documents/certificados.pdf (certificados, opcional)

Para executar:
1. Extrai a pasta.
2. Coloca as imagens paradox.jpg e chest.jpg dentro de assets/.
3. Opcionalmente, coloca profile.jpg na mesma pasta.
4. Abre index.html no navegador.

Antes de publicar:
- Substitui TEU-EMAIL-AQUI pelo endereço de email correto.
- Coloca o currículo e os certificados em documents/ com os nomes indicados.
- Confirma os níveis de idiomas e os dados das experiências.

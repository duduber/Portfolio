# Portefólio — Duarte Berardo

Website estático feito com HTML, CSS e JavaScript, preparado para publicação no GitHub Pages.

## Personalização antes de publicar

1. Substitui `TEU-EMAIL-AQUI` em `index.html` pelo teu endereço de email.
2. Coloca a fotografia escolhida em `assets/profile.jpg`. A fotografia pode ser a imagem a preto e branco do campeonato, desde que seja uma fotografia nítida e adequada ao contexto profissional.
3. Adiciona os teus PDFs à pasta `documents/`, com os nomes `cv.pdf` e `certificados.pdf`, ou altera os links em `index.html`.
4. Confirma os níveis de idiomas, formação e descrição dos projetos antes de publicar.
5. Confirma o endereço do jogo no itch.io e substitui o link se necessário.

## Publicar no GitHub Pages

1. Cria um repositório público no GitHub, por exemplo `portfolio`.
2. Extrai todos os ficheiros deste ZIP e coloca-os na raiz do repositório.
3. Abre **Settings → Pages**.
4. Em **Build and deployment**, escolhe **Deploy from a branch**.
5. Seleciona `main` e `/ (root)` e guarda.
6. Aguarda pela publicação. O endereço será semelhante a `https://duduber.github.io/portfolio/`.

Não é necessário instalar dependências nem executar um servidor para publicar.
